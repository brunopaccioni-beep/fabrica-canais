Fabrica Canais

A private publishing tool for the owner's own YouTube channels.

What it does

Fabrica Canais is a small desktop tool used by its owner to manage only the YouTube channels he owns. It uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos the owner produced, with their titles, descriptions, captions and thumbnails;
  • schedule when those videos are published;
  • read the channel's own statistics (views, watch time, subscribers) to write a private weekly report.

It is not offered to the public. It does not sign in other people and does not access any channel the owner does not control.
